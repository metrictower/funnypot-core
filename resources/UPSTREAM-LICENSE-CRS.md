# OWASP CoreRuleSet — upstream license & provenance

funnypot's CRS-derived attack templates (`templates/attack-crs/*.yaml`, generated by
`funnypot compile-crs`) are derived from the **OWASP CoreRuleSet**.

- Source: https://github.com/coreruleset/coreruleset
- Pinned release: **v4.29.0** (`ab3ccd5fcd691424ba3f320d4040c61417270193`) — the live pin is
  stamped into `resources/compiled/crs-manifest.json` at compile time.
- License: **Apache License, Version 2.0** (SPDX: `Apache-2.0`).
- Copyright: © 2006–2020 Trustwave and contributors; © 2021–2026 CRS project and contributors.

This is a **different license family than nuclei-templates' MIT** — Apache-2.0 requires
preserving the copyright/license notice, stating changes, and carries a patent grant — so this
notice is kept separate from `resources/UPSTREAM-LICENSE.md`. The full, verbatim Apache-2.0
license text fetched from the pinned upstream is committed at
`resources/upstream-licenses/coreruleset.LICENSE.md` by `scripts/ci/check-license.sh`.

## Statement of changes (Apache-2.0 §4)

funnypot does **not** redistribute CoreRuleSet `.conf` files. It reads them at build time and
derives NEW artifacts:

- Only the `@rx` and `@pmFromFile` operators are ported; `@detectSQLi`/`@detectXSS` (libinjection)
  and all non-detection operators are dropped and audited in `resources/skipped-crs.json`.
- Per attack class (sqli/xss/lfi/rce), the portable PL1 rules are aggregated into ONE broadened
  regex alternation. CRS rule ids, `msg`/`logdata` text, `tag`s, severities, and the anomaly-score
  bookkeeping are **not** copied into any served artifact — only the detection intent (broadened
  match + attack class) is kept, behind funnypot's own hand-authored response archetype.
- CRS severities are re-mapped to funnypot's scale (`CRITICAL → high`, respecting the default
  severity ceiling); PL2–PL4 rules are excluded unless explicitly opted in.

A build-time fingerprint-safety gate (`scripts/ci/check-fingerprint-safety.php`) additionally
guarantees no CRS signature string ever reaches a served response body.
